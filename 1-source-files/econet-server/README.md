# Econet server files for Elite over Econet

This folder contains Econet server files for Elite over Econet.

* [$.!BOOT.bin]($.!BOOT.bin) is the L3FS boot file

* [FS3v126.ssd](FS3v126.ssd) is the disc image for the L3FS server

These files are used by oaknut-disc when building a Level 3 File Server hard disc image.
